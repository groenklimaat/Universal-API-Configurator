🔒 Privacy Statement

Universal API Monitor — Last updated: 2026

TL;DR: Wij bewaren niets. Alles blijft in jouw browser of op jouw eigen toestel.

1. Wie zijn wij?

Universal API Monitor is een open-source, self-hosted applicatie. Er is geen centrale server die jouw gegevens verzamelt. Wanneer je deze applicatie gebruikt, draait alles op jouw eigen computer, telefoon of ESP32.

2. Welke gegevens verzamelen wij?

Geen. Specifiek:

  • ❌ Geen cookies voor tracking
  • ❌ Geen analytics (Google Analytics, Plausible, ...)
  • ❌ Geen advertenties
  • ❌ Geen user accounts
  • ❌ Geen server-side logging van jouw requests
  • ❌ Geen IP-adressen opslaan

3. Waar worden jouw gegevens bewaard?

Alle gegevens die jij invoert (API keys, URLs, configuratie) worden uitsluitend lokaal bewaard:

  • 🗄️ Browser localStorage — voor de webversie
  • 🔧 ESP32 Preferences (flash) — voor de embedded versie
  • 💾 Jouw eigen server — als je Flask zelf host

Deze gegevens verlaten jouw toestel nooit zonder dat jij zelf een request verstuurt.

4. Wat gebeurt er als je een API aanroept?

Wanneer je op 🚀 Send Request klikt, wordt een HTTP-verzoek gestuurd naar de URL die jij hebt ingevuld. Dat verzoek gaat rechtstreeks naar die API — niet via ons.

  • De API-provider ontvangt: jouw API key, URL en eventueel body
  • Wat die provider doet met jouw gegevens → zie hun eigen privacybeleid
  • Wij hebben geen toegang tot deze gegevens

5. CORS-proxy

Als jouw browser het verzoek blokkeert (CORS), biedt de app een tweetal opties:

  • Eigen Flask-proxy (/api/proxy) — draait op jouw server, jouw gegevens blijven bij jou
  • Publieke proxy (corsproxy.io) — optioneel; de derde partij ziet jouw verzoek. Gebruik dit enkel voor niet-gevoelige testdoeleinden.

6. API keys

Jouw API keys worden nooit naar ons gestuurd. Ze worden:

  • ✅ Opgeslagen in localStorage van jouw browser
  • ✅ Verzonden naar de API die jij kiest (dat is het doel)
  • ❌ Niet gelogd op de server
  • ❌ Niet gedeeld met derden

Tip: gebruik waar mogelijk een beperkte key (rate-limited of read-only) en verwijder keys die je niet meer nodig hebt.

7. Jouw rechten (GDPR / AVG)

Omdat wij geen gegevens verzamelen, heb je in de praktijk:

  • ✅ Recht op inzage — alles staat in jouw browser, je kan het zien
  • ✅ Recht op verwijdering — klik op "🗑️ Clear" of wis localStorage
  • ✅ Recht op overdraagbaarheid — exporteer je log via "⬇️ Export"
  • ✅ Recht op bezwaar — je kan de app op elk moment sluiten

Heb je toch vragen over GDPR? Neem contact op via de repository waar je deze software vond.

8. Beveiliging

  • 🔐 HTTPS aanbevolen voor alle API-verzoeken
  • 🛡️ Keys worden niet in logs bewaard
  • 🧹 Bij "Clear log" wordt de monitor-historiek gewist
  • 💾 Bij het verwijderen van localStorage ben je volledig "vergeten"

9. Kinderen

Deze app is niet gericht op kinderen onder de 16 jaar en verzamelt bewust geen gegevens van hen.

10. Wijzigingen

Wijzigingen aan deze privacyverklaring worden gepubliceerd op deze pagina. De datum van de laatste wijziging staat bovenaan.

11. Contact

Voor vragen over privacy, open een issue op de GitHub-repository waar je deze software hebt gevonden.

🌈 Privacy by design — geen data, geen zorgen. ✨
